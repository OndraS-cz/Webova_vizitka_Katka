# Statická webová vizitka | Mgr. Kateřina Severová

Tento projekt obsahuje moderní, plně responzivní jednostránkový web (One-Page Website) vytvořený pro soudní překladatelku a tlumočnici.

## 🚀 Živá ukázka
Web je dostupný na adrese: https://katerina.severa.name/

## ✨ Klíčové vlastnosti
* **Moderní design:** Čistý a profesionální vzhled inspirovaný návrhem z Canvy.
* **Responzivita:** Plně optimalizováno pro mobilní zařízení, tablety i desktopy.
* **Interaktivní prvky:** - Reveal animace při scrollování (Intersection Observer API).
  - Hover efekty na kartách služeb.
  - Ošetření telefonního čísla (aktivní pouze na mobilu).
* **Technologie:** Čisté HTML5 a CSS3 (bez externích knihoven).

## 🛠️ Použité technologie
* **HTML5:** Sémantické značkování.
* **CSS3:** Flexbox, CSS Grid, Custom Variables.
* **JavaScript:** Lehký skript pro detekci viditelných prvků (reveal efekt).
* **Google Fonts:** Písmo 'DM Sans'.

## 📂 Struktura projektu
* `index.html` - Hlavní struktura webu.
* `style.css` - Kompletní stylování a mobilní responzivita.
* `/` - Adresář obsahuje potřebné obrazové podklady (.jpg).
